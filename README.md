# Kosher Low-Carb Kitchen

148 simple kosher keto & low-carb recipes (English + Hebrew) with full nutrition data, dairy/pareve labels, and print support.

Live book: https://hraanan.github.io/kosher-lowcarb-kitchen/

Recipes are adapted from the creators credited on each recipe page. Personal project.

- `data/recipes/*.json` - recipe data
- `template.html` + `build.ps1` - build `book.html` / `index.html`
